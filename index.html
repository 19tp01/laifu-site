Laifu

A personal assistant run by Terry Pi for himself and his family.

Laifu is a private, non-commercial assistant. It is not offered to the public. It uses Google sign-in only for accounts its owner controls, to read Gmail (read-only) and to read and edit Google Docs that the family shares with it.

Privacy policy

What it accesses. Only the Google data for the scopes granted at sign-in: Gmail messages (read-only) and Google Docs the account has access to.

How it's used. Only to answer the account owner's own requests, such as finding an email or updating a shared family document. Nothing is used for advertising, sold, or shared with third parties, except that content needed to answer a request is sent to the AI model provider (Anthropic) to process that request.

Storage. Sign-in tokens are stored on the owner's own computer. Email content is not copied into a separate database; parts of it may remain in the assistant's private conversation history on that computer.

Google API Services. Laifu's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access. Remove Laifu at any time at myaccount.google.com/permissions.
